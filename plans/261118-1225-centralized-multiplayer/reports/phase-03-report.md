# Phase 3 directory handoff

The Colyseus `directory` room starts headless Godot workers on UDP 7778–7780. It publishes signed worker state after creator admission, leaves seat arbitration to each worker, and clears a slot only after process ownership and UDP binding are both clear. The directory persists launch identities so its own process can restart while workers keep playing. Persistent launch files contain room identity, generation, name, and deadlines.

## Client protocol

Connect to the configured root `LOBBY_URL` and call `join_or_create("directory")`. The service pushes `rooms` on connection and when the directory changes. Send `list` to refresh. The response has `rooms`, `createAvailable`, and `createCode`. Each entry carries `roomId`, `name`, `humans`, `capacity`, `mode`, `state`, `available`, and `joinable`. Use `joinable` to enable Join. Create can return `server_full` with the display string **Server full**.

Send `create` with `{requestId, name, role, protocol, clientBuild}` or `join` with `{requestId, roomId, name, role, protocol, clientBuild}`. Use a fresh opaque request ID for a new action. An identical repeat on the same lobby session and operation returns the current outcome. Names are trimmed and capped at 16 Unicode characters. A mismatched `protocol` or `clientBuild` is rejected with `client_incompatible` before any seat or port is reserved. The requester alone receives `admission` with `{requestId, roomId, generation, udpEndpoint: {host, port}, ticketId, secret, ttlMs}`. `ttlMs` is the worker-reported remaining ticket lifetime; the client sets a monotonic local deadline from it and never compares its own wall clock with an absolute expiry. Send `cancel` with `{requestId}` to abandon a pending Create or Join; the directory forwards the worker `cancel` by request ID and releases a reservation that arrives late, on the original worker generation. When a match starts while a ticket is outstanding, the requester receives `room_started` with `{requestId}` and an ENet proof for that invalidated ticket also receives `room_started`. Errors use `admission_error` with `{requestId, code, message}` and a refreshed `rooms` message. A `degraded` code means worker supervision is unusable and clients show **Server offline** with Retry; `GET /health` returns HTTP 503 for the same condition. The default ticket TTL is 15 seconds. Directory disconnects leave pending tickets to their worker expiry and admitted ENet players in their matches.

## Running the service

Use Node `26.13.0`. From `multiplayer-server/`, run `npm ci`, `npm run build`, then `npm start`. A local run requires an absolute `WORKER_EXECUTABLE` and `ADMISSION_SECRET_FILE`. With a Godot editor executable, set the absolute `WORKER_PROJECT` to this repository. Configure a private persistent `WORKER_STATE_DIR` shared across directory restarts. The credential file contains 32 bytes encoded as lowercase hex and has mode 0600, or 0640 when shared with a trusted group. `LOBBY_PORT` defaults to TCP 2567 and `CONTROL_ENDPOINT` to `127.0.0.1:2569`. Both listeners bind IPv4 loopback. `GET /health` returns 503 during directory reconciliation, while worker ownership probes are failing (degraded readiness), and while stopping; it returns 200 once that window ends, including when the roster is full.

The [deployment templates](../../../multiplayer-server/deploy/) use a dedicated `htd` service user and independent systemd instances per port. Place the compiled service and pinned Node at the paths in the units. Install the manager and worker template units under `/etc/systemd/system/` and the worker-unit policy under `/etc/polkit-1/rules.d/`. Provision `/etc/hold-til-dawn/multiplayer.conf` from the example with the exported worker path, protected credential source, private state directory, and public endpoint. Reload systemd and enable the manager service. Workers start on demand. Keep the directory's state directory across process restarts.

Configure the TLS reverse proxy for the public WSS DNS name, including Colyseus matchmaking and WebSocket upgrades. Open TCP 443 and UDP 7778–7780 on the public firewall. Keep the internal HTTP and control ports private. Read manager logs with `journalctl -u hold-til-dawn-multiplayer.service` and a worker with `journalctl -u hold-til-dawn-worker@7778.service`. To restart the directory while retaining matches, send SIGHUP to the manager service. Systemd restarts the manager after it exits. For a whole-service stop, use `systemctl stop hold-til-dawn-multiplayer.service`. The manager sends authenticated close to the workers and waits before escalating an unresponsive unit. [Systemd service documentation](https://www.freedesktop.org/software/systemd/man/latest/systemd.service.html).

## Verification

- `npm test --prefix multiplayer-server` passed on macOS arm64 with Node 26.13.0 and Godot 4.7.2. Real Colyseus connections and Godot workers exercised creator-first publication, five admitted seats, one winner for two concurrent final-seat requests, expired and old-generation tickets, three-room capacity and **Server full**, idempotency, leader succession, and waiting-only admission through the next match.
- The same suite passed lobby-session loss before and after ticket issuance, worker survival through manager crashes during play and before UDP bind, signed registration rejection and heartbeat loss, unregistered UDP occupancy, real process death, and a 60-second empty-room exit. A new worker reused the port with a new generation. Application logs and public payloads contained zero admission credentials, including with Colyseus message debugging requested.
- The same suite covered compatibility, cancellation before and after assignment, and Start between assignment and ENet proof: the original session receives WSS `room_started`, and the invalidated ENet proof also receives `room_started`. A cancelled Create frees its port for reuse. An ownership-probe failure returns HTTP 503 with directory code `degraded` and keeps an authenticated, heartbeating room online; a 1,600 ms control-only gap also kept the established room online, and the injected 550 ms probe error was observed without blocking the event loop. The hosted client runner additionally verified immediate cancellation retries and a stale absolute expiry reaching the client, which the monotonic `ttlMs` deadline ignores.
- `python3 tests/match-worker-wss.py /path/to/Godot` passed on macOS arm64 after importing the project and installing the service dependencies. It starts a loopback TLS directory with a temporary CA and connects the native Godot Colyseus SDK over WSS. The CA is configured in the project's `network/tls/certificate_bundle_override` before the GDExtension loads; a runtime setting change comes too late for the SDK. The same endpoint rejected an untrusted CA and a hostname mismatch with `TlsInitializationFailed`. The system trust store was left intact. This is local evidence only: it does not verify the public built-in WSS endpoint, public certificates or exported clients.

## Still unverified

- The Linux systemd units, polkit authorization, `Job`/`MainPID` ownership parsing, `execve` marker visibility, graceful and escalated stop, port release, production TLS configuration, and firewall exposure are unexecuted; the deployment templates are local evidence only. This workspace runs macOS and its local Linux container daemon was unavailable.
- The public built-in WSS endpoint, public TLS certificates and DNS, native Godot SDK trust against public certificates, macOS and Windows exports, the Linux worker export, cross-network play, and three-room capacity under hosted load remain open.
