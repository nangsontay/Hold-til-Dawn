# Hold 'til Dawn (prototype)

Godot **4.7.2** (the standard editor, no .NET needed). All game scripts, tests and art tools are GDScript. Rules from the GDD live in `game_sim.gd` (`GameSim`), input and rendering in `main.gd` (`Main`), and shared terrain and collisions in `src/world/world_geometry.gd`. The former C# paths cited below are section headings in the GDScript port. The C# version is kept on the `csharp-demo` branch.

## Run

- Open the project in the Godot 4.7.2 editor (the standard build; no .NET needed). Commands below use the Godot executable as `godot`.
- **Play solo.** In a debug build, run `godot --path . -- --autoplay` to start an offline match immediately with two bots.
- **Host locally.** In a debug build, run `godot --path . -- --autolobby` to open an ENet crew lobby on UDP 7777 with two bots. Use `--autohost` to start the hosted match immediately. From another instance, run `godot --path . -- --autojoin` to connect to `127.0.0.1` and join while the lobby is waiting.
- **Play online:** open the desktop build, set your callsign and role, then choose **Play** to browse the hosted directory (see [Play](#play)).

## Play

Open the desktop build, set your callsign and role, then choose **Play**. Create a room or join a waiting room with an open seat. The creator leads the crew. Every human marks Ready and at least one chooses Engineer before the leader can start; there is no minimum crew size (up to 5). When all three rooms are occupied, use **Refresh** to check for openings or join a waiting crew with space.

Esc leaves the room. During a match, a departure pauses play and transfers leadership to the next human if the leader left. The remaining crew votes to continue or end, then whether to assign replacements. After a result, the crew can play again in the same room.

### Development and LAN

Install Godot 4.7.2 and Node 26.13.0. From the repository root, import the project, install the locked dependencies and build the service.

```sh
git submodule update --init
python3 tools/fetch-colyseus-sdk.py
godot --headless --path . --import
npm ci --prefix multiplayer-server
npm run build --prefix multiplayer-server
```

Run the local service in its own terminal. It owns the temporary worker processes and closes them on Ctrl-C. Use a fresh directory for an independent rehearsal. Keep the same directory and key across directory-only restarts.

```sh
run_dir=$(mktemp -d)
(umask 077; openssl rand -hex 32 > "$run_dir/worker.key")
env WORKER_EXECUTABLE="$(command -v godot)" WORKER_PROJECT="$PWD"   ADMISSION_SECRET_FILE="$run_dir/worker.key" WORKER_STATE_DIR="$run_dir/workers"   npm start --prefix multiplayer-server
```

Launch a client with `godot --path . -- --lobby-url=ws://127.0.0.1:2567`. The argument takes precedence over `LOBBY_URL`. For a private LAN, set `WORKER_HOST` on the service to its LAN IP, use a LAN-only HTTP/WebSocket reverse proxy for loopback TCP 2567, and pass `--lobby-url=ws://<LAN-proxy-address>` to debug clients. Allow UDP 7778–7780 from the LAN. An exported release client requires WSS. The direct debug server uses `godot --headless --path . -- --server` on UDP 7777. Run a local debug client with `godot --path . -- --autojoin` to connect directly to that server.

Run `python3 tests/release-verification.py` for clean and impaired UDP load. It starts a real directory, three workers and fifteen headless Godot client peers, then releases the processes and ports. Use `--mode clean` or `--mode lossy` to run one network. `GODOT_BIN` overrides the Godot executable. Pair it with `npm test --prefix multiplayer-server`, `python3 tests/hosted-client-integration.py`, `python3 tests/match-worker-integration.py "$(command -v godot)"`, and the simulation and geometry checks below.

See the [deployment guide](docs/deployment-guide.md) for Docker and systemd deployment.

## Operate the hosted service

### Build a matched release

Use one source revision, the Godot 4.7.2 editor and matching export templates, and the pinned Node 26.13.0 Linux x64 distribution. In the command below, supply the paths to the extracted `linux_release.x86_64` export template and the extracted Linux Node distribution. The script imports assets in a staging project and generates the worker PCK. The headless executable loads the PCK beside it. The worker pack omits the client native SDK binary. Desktop exports include the SDK and a baked-in directory hostname. Keep the `RELEASE` manifest and previous matched artifacts for rollback. Verify upstream export-template and SDK binary notices and platform signing requirements before distributing desktop builds.

```sh
PACKAGE_DESKTOP=1 multiplayer-server/deploy/package-release.sh   /absolute/output/0.1.0 0.1.0 play.example.net   /absolute/templates/linux_release.x86_64 /absolute/node-v26.13.0-linux-x64
```

With three arguments the script builds the service and worker PCK for local inspection. Omit `PACKAGE_DESKTOP=1` if the desktop export templates are unavailable. For a local smoke test of the packaged service and worker PCK, run `python3 tests/hosted-client-integration.py --release /absolute/output/0.1.0`. Validate the Windows and macOS release exports on their target machines.

### Provision the Singapore VM

1. Use a Linux x86-64 VM with 4 vCPU and 4 GB RAM. Create the system account and group `htd`, then create `/var/lib/hold-til-dawn/workers` owned by `htd:htd` with mode 0700. Copy the release into `/opt/hold-til-dawn-releases/<release-id>` and initially point `/opt/hold-til-dawn` at it with an absolute symlink. Keep the releases owned by root.
2. Install the directory, worker, DDNS service and DDNS timer from the release's [deployment templates](https://github.com/nangsontay/hold-til-dawn-server/tree/main/deploy) in `/etc/systemd/system/`. Install `50-hold-til-dawn.rules` in `/etc/polkit-1/rules.d/`. Copy the release's `multiplayer.conf.example` to `/etc/hold-til-dawn/multiplayer.conf` and verify both public endpoints use the same hostname. Generate the worker key on the host with `openssl rand -hex 32` redirected to the configured file using a 077 umask. Set ownership to `htd:htd` and mode 0600. Keep it and the worker state directory across restarts and releases.
3. Delegate the public name to a DNS provider supporting RFC 2136 updates. Provision a TSIG key with permission to update only that hostname's A record. Install `nsupdate` (usually `bind9-dnsutils`), `curl` and Python 3. Copy the release's `ddns.conf.example` to `/etc/hold-til-dawn/ddns.conf`. Set the zone, authoritative update server, and TSIG key file. Keep that file root-owned with mode 0600. Use a VM public IPv4 that matches the HTTPS IP discovery response. Remove a stale AAAA record unless you provision IPv6 separately. Run `systemctl daemon-reload`, `systemctl enable --now hold-til-dawn-dns.timer` and `systemctl start hold-til-dawn-dns.service`. Verify the authoritative answer with `dig @<authoritative-server> <game-hostname> A +short`.
4. Allow inbound TCP 443 and UDP 7778–7780. For HTTP-01 certificate issuance and renewal allow TCP 80. Keep the service HTTP listener TCP 2567, the worker management listener TCP 2569 and the development UDP 7777 private. Before enabling the TLS vhost, obtain the first certificate with `certbot certonly --standalone -d <game-hostname>` while TCP 80 is free. Then install the release's `nginx.conf.example` in the nginx HTTP configuration and create `/var/www/letsencrypt`. Validate with `nginx -t`. The proxy must forward `/health`, `POST /matchmake/joinOrCreate/directory`, and WebSocket upgrades at `/<processId>/<roomId>`.
5. Enable nginx and `hold-til-dawn-multiplayer.service`. Check `curl -fsS http://127.0.0.1:2567/health` on the VM and `curl -fsS https://<game-hostname>/health` from another network. A healthy service returns HTTP 200 including when full or draining. HTTP 503 means the directory is reconciling worker ownership or stopping.

### DNS and certificate rehearsal

Power down the VM after draining, obtain a new public IPv4, and boot. Watch `journalctl -u hold-til-dawn-dns.service`. Compare the authoritative and a public resolver's A records before and after boot. Honor the old record's TTL. Use an already exported client on an external network to open Play and join a match over the same hostname. Check a valid certificate, then verify the client refuses an untrusted certificate and a trusted certificate for a different name on isolated test endpoints.

Keep TCP 80 and the nginx challenge path available for HTTP-01. Reconfigure the original standalone certificate for ongoing webroot renewal while nginx is running. Run `certbot reconfigure --cert-name <game-hostname> --webroot-path /var/www/letsencrypt --authenticator webroot`, then `certbot renew --dry-run`. Set the Certbot deploy hook to `/opt/hold-til-dawn/deploy/reload-certificate.sh` and confirm the Certbot timer is enabled. After a renewal, check the served chain and expiry from another network and confirm that active matches continue through the nginx reload.

### Recovery, drain and rollback

- Read directory logs with `journalctl -u hold-til-dawn-multiplayer.service` and worker logs with `journalctl -u hold-til-dawn-worker@7778.service` (or 7779/7780). Allocation and release log lines include room ID, worker generation and UDP port. Keep admission credentials and TSIG material private.
- For a compatible directory-only restart, run `systemctl kill --kill-whom=main --signal=HUP hold-til-dawn-multiplayer.service`. Recheck health and confirm the existing rooms return with the same worker PIDs and occupancy. ENet matches continue while the directory restarts.
- For an incompatible release, run `/opt/hold-til-dawn/deploy/drain.sh on` as an operator. Confirm health shows `"draining":true`. Existing crews can finish their match. Previously issued tickets can settle or expire. Ask waiting crews and crews at results to leave. `drain.sh wait` waits for all three leases to clear, including the 60-second empty-room timer. If you changed the ports or state path, pass the matching `LOBBY_PORT` and `WORKER_STATE_DIR` to the operator scripts.
- Rehearse by placing the new and preceding matched bundles under `/opt/hold-til-dawn-releases/`. With the drained flag still set, run `/opt/hold-til-dawn/deploy/activate-release.sh <release-id>`. The script verifies the pinned versions (Node `v26.13.0`, Godot `4.7.2.stable.official.ed1daf0bf`, and the package manifest checksums), switches the symlink with `flock`/`mv -Tf` and starts the directory. Rehearsal requires both a compatible and an incompatible loopback directory peer to be rejected correctly, and an authenticated worker launch and close-acknowledged exit on all three slots while drained. It restores the preceding target if health or rehearsal fails; if the restored release cannot complete the same rehearsal, keep admissions drained until it is verified manually. Confirm the service versions and manifest, then use an isolated staging instance with admissions open to test the matched client against the directory and worker, plus signed worker registration. Reopen production admissions with `drain.sh off` only after confirming the matched exported client over public WSS and ENet in staging. To roll back, repeat the drain and activate the previous release ID. Distribute the corresponding client builds together. Rehearse this drain-and-rollback, including a deliberately failed activation, on the target Linux host; it has not run there yet.
- Before a planned VM shutdown, run `drain.sh on` and then `drain.sh shutdown`. Confirm the three worker units are inactive and UDP 7778–7780 are free before powering down. The drain flag persists across cold boots. Run `drain.sh off` after DNS, health and the release have been checked. An ordinary service stop sends authenticated close to existing workers immediately and is appropriate when you intend to end those rooms.

### Accepted risks and decisions for the three-room test

- **Anonymous room and seat hoarding is an accepted risk (user decision).** The lobby has no per-IP limits — neither nginx (`limit_conn`/`limit_req`) nor the directory applies them; only per-socket caps exist (10 messages/second, 256 clients). A few scripted sessions can occupy all three rooms or hold seats indefinitely. No code change is planned for the three-room test; add per-IP limits only if abuse occurs.
- **Departure policy (user decision).** Lost upstream traffic freezes the affected match within 1 s (after 900 ms of input silence), but the departure is final only once ENet confirms the loss through its own disconnect/timeout. If the player's traffic returns first, the crew resumes with the same seats and no vote. A player whose connection stays up but who sends no input for 12 s is removed as a departure, so the crew gets the same vote. The client retains its 4,800 ms liveness watchdog inside the 5-second budget.
- **Native-SDK WSS has only been proven locally**, through a temporary CA configured in the project's `network/tls/certificate_bundle_override` (repeatable check: `python3 tests/match-worker-wss.py /path/to/Godot`, run after importing the project and building the service; the CA must be set before the GDExtension loads). It has not run against public certificates or exported clients.
- The vendored `addons/colyseus/plugin.cfg` reports version `0.18.0` while `addons/colyseus/version.json` pins the SDK at `0.18.10`; both are upstream layout, preserved as-is. The five SDK binaries are fetched by `tools/fetch-colyseus-sdk.py`, not committed; their SHA-256 digests are recorded in `addons/colyseus/SHA256SUMS` and verified by the script and during packaging.

## Controls
WASD move, mouse aim, LMB attack with the selected weapon (bows shoot toward the cursor), E hold 2 s with a crafted key to unlock an expedition chest, then select loot / hold to assemble the locator radio at the workbench / gather / repair door or tower (Engineer, needs the hammer) / revive / pick up a dropped item, 1-4 or mouse wheel select a hotbar slot, Tab inventory and (at the base chest) base storage / (at an unlocked island chest) its eight storage slots with drag and drop, G give the selected stack to a teammate in reach or drop it, Q bandage, C workbench (number keys or click; most crafts take 3 s), B build menu (Engineer: wood wall, stone wall, tower; R turns a wall, LMB places, RMB cancels), RMB healing flask (Healer), F (hold 2 s, Engineer at night) enter or leave the base through a closed door, V skip-day vote, T start a 6-second tower build at your feet, M large map (the minimap in the top left follows you), Ctrl + wheel zoom, Esc pause menu (closes open panels first).

Day-skip vote (FML-14): press V by day to vote or withdraw. Votes count once 180 s of the day have passed; the day then ends when at least 60% of the people vote (bots do not vote; one vote when playing solo). A day lasts at most 360 s. The 15-second dusk warning (BAL-05) follows, then night. For a quick test, the debug-only F9 key (host) ends the current phase.

## What is in
- Home farms (Coconut Grove, Limestone Flats and Herb Meadow) use one shared centre and a compact 6-by-5-tile elliptical gathering radius, about 29% less area than the old 6.5-tile random spread. They have at least 36 wood, 32 stone and 36 herb nodes, with an open central aisle. Ground is opaque over every resource footprint, feathering only beyond the farm boundary, and the minimap uses the same surface. Primary resources are selected from these sites rather than duplicated elsewhere.
- Outside those three home farms, wood, stone, herbs and ground grass/pebbles are reduced by 25% using a deterministic placement pass. All six garden beds remain populated (six herbs each), the cave retains 24 exterior stone nodes, and all 19 interior titanium veins remain. `tests/ResourceLayoutCheck.tscn` checks rail collisions, boss crossings, farm coverage, aisles and material counts; `tools/TerrainPreview.tscn -- --farm-review` captures the home farms, garden, bridges and map.
- Resource placement reserves a full-width approach extending three tiles past both ends of every bridge. Trees, rocks and titanium cannot obstruct the bank-side landing lanes when landmark changes redistribute the surrounding resources; the largest boss body can still cross.
- Old Fishing Pier has three rods with hanging lines and bobbing floats, discarded wrappers, tins, bottles and fishing line, plus staggered jumping fish and splash rings. These are local visual decorations, with no fish physics, pathfinding or gameplay spawns. Sea positions are checked once when the pier is built.
- Weather Station has a walkable nine-by-seven-tile hut with a south doorway, solid walls, tiled floor, equipment desk, chair, shelving and sealed windows. Its metal roof fades on entry, and the outside scenery is completely hidden while inside, as at Southwest Cave. Furniture is display-only; rescue components and resources are kept outside. `tools/TerrainPreview.tscn -- --station-review` captures both locations, including hut entry, interior and exit.
- Crafting has **18 recipes in 3 tabs**: BASIC (arrows, light armour, bandages, Revival kits, Engineer generator repair, gathering kits, crafting kits and chest keys); STONE after night 1 (stone spear, bow, long spear, stone armour, healing flask and Engineer field repair kit); TITANIUM after the first boss (titanium blade, stun maul, titanium armour and explosive arrows). A bow costs 6 wood + 2 titanium and comes empty; craft 5 arrows separately for 1 wood. A key costs **2 wood + 2 stone**, available from day 1. Most crafts take 3 s; generator repair takes 5 s for 100 HP. A carried crafting kit (6 wood + 4 stone) reduces both times by 20%, without stacking; gathering kits retain their separate 20% gathering-time reduction. Haste tonics, poison flasks and vine traps are **loot only**. Walls and towers still use the build menu.
- Tactical combat (`src/gameplay/GameSim.TacticalItems.cs`): the long spear hits the nearest two enemies along a narrow 2.6-tile thrust; the maul attacks slowly and stuns normal foes for 0.8 s (bosses slow 25% for 1 s). Traps root one normal enemy for 2.5 s, expire after 120 s, and are capped at three per player / twelve total. Poison and healing zones last 5 s and pulse at 2 Hz for 8 damage / HP per second, with no friendly fire or stacking; at most 16 areas exist. Haste grants 20% movement speed for 8 s. Explosive arrows need a bow in the bag and always consume special ammunition, including with the Scout's starter bow; select the special arrow stack to fire it. Engineer field repair restores up to 100 HP to a nearby door, wall or tower after 3 s standing still, obeys wreck / breach restrictions and keeps the kit if interrupted. Temporary effects clear at dawn and match end. Bots craft allowed equipment / use looted tactical supplies through the same gameplay rules.
- Resource visibility: all placed living trees (including palms and mangroves), fallen wood, loose rocks, rock spires and herb-like plants are harvestable with E. There are no decorative-only trees or dead trees. These world resources supplement the original `4 + 3n` resource clusters and regenerate at dawn. Buildings, the cave cliff, bridges and industrial landmark structures remain scenery. Each resource keeps its own sprite and footprint through snapshots, and loses its collider when exhausted.
- Harvest art is generated by `tools/PixelHarvestDamage.cs`: trees lose lower boughs or whole fronds as their trunk cut deepens; stone loses large angular chunks with bright fracture faces; herbs lose outer leaves and flowers, and garden rows empty progressively. Each of the four stages changes the visible silhouette, with a stump, rubble or cut stems after the fifth unit. The worked node jolts, briefly brightens and throws material-coloured chips on the contact frame of the character animation; five small slots under that node show units remaining and progress toward the next unit. Trees and rocks keep their scale and collision footprint until exhausted. The daytime roamer warning "Something is moving out there..." has been removed.
- 5 day/night cycles on an 11 x 7 tile base (GDD: 15 x 10) with doors A (west), B (north), C (east), no south door; players enter only through doors, and at night only the Engineer (hold F) or anyone through a broken door.
- Players, enemies and bots share scenery/resource/building colliders from `src/world/WorldGeometry.cs`. Movement is swept in small steps; the server validates player movement and acknowledges predicted inputs. Grass, pebbles, bushes and herbs stay walk-through. Enemies and bots navigate around obstacles with cached A* paths (pressed against a solid, they slide toward the next path cell instead of stopping).
- Bot teammates (`src/ai/bots.gd`, not in the GDD, for demos and solo tests): in development builds the lobby leader adds or removes them (max 5 players), while in release builds they appear only as replacements after a disconnect vote (the "bot" timeout vote); a bot takes the missing role (Engineer, then Healer, Scout). They run on the server with the same rules as people: dodge boss slams, revive downed teammates, Healer flasks, fight, Engineer door repair, gather by day and craft near dusk, hold the attacked door at night. Only people count for the day-skip vote.
- Night waves spawn out of sight 25-35 tiles in front of attacked doors. A paced director (`src/ai/GameSim.NightSpawns.cs`) creates at most one regular enemy per tick. Nights last at most 420/480/420/480/480 s. Night 1 starts at 20 s, with 60 s between waves and 2 s between enemies; nights 2-5 use first delays 17.5/15/15/15 s, wave intervals 52.5/45/37.5/30 s, and spawn spacing 1.3/1/0.7/0.5 s. An empty field brings the next wave in 5 s. Alive limits rise 12/16/20/24/28. Enemies are weaker and cheaper than the GDD (Grunt 40 HP / 7 damage, Spitter 28 / 6, Wrecker 70 / 8), so more of them come; Grunts only on nights 1-2, Spitters from night 3, Wreckers from night 4. Each night has a quota (about 22/61+boss/73/111+boss/190 for three players), shown by the night bar under the generator. The boss of nights 2 and 4 comes at 150 s (sooner once the field is cleared) and counts toward the quota. Tuning is in `config/ai/ai.tres`.
- **Expedition chests and locator radio** (`src/world/GameSim.Supplies.cs`): **20 chests** per match: one at each of the 14 expedition landmarks and six scattered around the island, away from the outpost and three home farms. Neither map size shows chest markers. Exactly three distinct landmark chests contain the Radio battery, Antenna assembly and Locator circuit; scattered chests never contain radio parts. Each chest is a persistent **8-slot container** with wood (4-10), stone (3-8), herb (2-5), titanium (1-3) and sometimes one support item. Support variety is guaranteed across the match; stacks obey normal capacity limits. Craft a key, stand close, and **hold E for 2 seconds** to unlock; movement, damage, attack, release or loss of the key cancels without charging. One key is consumed only on completion. A locked padlock/progress ring changes to a raised lid, broken latch and green indicator. Unlocking only opens the storage panel: **drag the desired stack into your bag**, or store items back, just like base storage. No automatic looting. Radio parts are selected the same way, then shared by the team without taking a bag slot, even with a full bag. Unlocked chests reopen with E or Tab without another key; leaving reach closes the panel and rejects transfers. Contents of locked/distant chests remain unpublished. Chest state, remaining loot and found parts persist through dawn; no refills or duplicate parts. With all three parts, hold E at the workbench for 3 seconds by day, before night 5 begins (day 5 is still allowed); movement/damage/release cancels assembly without losing parts. Night 5 without an assembled radio loses the match; otherwise defend a clear landing pad for extraction. `tests/ExplorationChestCheck.tscn` checks 64 seeds, distribution, contents, unlocking interruptions, selective transfers, persistence, recipes and the radio deadline. `tools/ExplorationChestPreview.tscn` captures locked/unlocking/open chests, the selection panel, radio and marker-free map; `tools/TacticalCraftPreview.tscn` captures all three crafting tabs.
- Daytime roamers start beyond 10 tiles, checking every 8 seconds instead of 15; encounter probability rises to 65% at 45 tiles and is higher near the northern swamp. Groups stay pairs, with at most 14 daytime roamers; distant unseen roamers withdraw after 25 seconds. At dusk they head for an attacked door. The Mangrove Swamp, its pools, mangroves and map label have moved to the northwest interior.
- Exploration now has 860 ambient harvestable resource sites (previously 526) and two rivers. Yellow trail surfaces and decorative slope steps are hidden in the world and minimap; route data still reserves clear walking corridors. Landmark soil continues over hidden trails. River bridges, the fishing pier and cape platform remain visible. Named landmarks and unnamed trails gain survey camps, research consoles, broken carts, quarantine signs, cargo stacks and water pumps. All added expedition props are **non-harvestable** scenery; their native pixel-art sources are in `tools/PixelExpeditionProps.cs` and PNGs in `art/landmarks`.
- Rivers (`src/world/IslandRivers.cs`, drawn by `src/world/view/Main.Rivers.cs`): one in the west and one in the east, each running from the north coast to the south coast. West: the northern river course separates Weather Station and Bayside Wreck from the outpost; three bridges connect the northern expedition trail, door A's road and the Southwest Cave trail. The northern swamp is east of the expedition crossing. East: west of the Ruined Base, bridged on the main route north of the Herb Meadow and on door C's road. The water stops everyone like the sea (`IslandMap.OnLand`): players, enemies, bosses and bots cross only on a bridge, and the route grids mark the water solid, so bosses landing past a river come over the road bridge. Grass, trees, rocks and landmarks keep off the water and its muddy banks. Bridges are 3.2 tiles wide, with continuous solid rails and a clear centre lane wide enough for bosses: stone abutments on both banks, a plank deck on two beams, piles in the water, a rail on each side and a lantern on each corner post. A path the water cuts away from a bridge turns along the bank to the nearest bridge on that side (`src/world/WorldRivers.cs`), so no path ends at the water. The maps show the rivers and bridges.
- Landmark surfaces share a palette between the world and minimap: exposed limestone, cave scree, gravel at the weather station, churned vehicle tracks, coastal sand, damp pond banks and garden earth. Bare areas have opaque centres, irregular feathered edges and no grass tufts; water, bridges, concrete and wooden decks retain their own surfaces. Landmark and bay names use black lettering with a black outline. `godot --path . tools/TerrainPreview.tscn` captures all 17 expedition sites, five bridges and the map in `.tmp/terrain-review/`.
- Landmark grounds and layouts are expanded to approximately 1.5 times their previous area (`WorldLandmarkScale.cs`: lengths grow by sqrt(1.5), while individual props keep their human scale). The pier and cape decks, pond and swamp expand as well. `WorldCompounds.cs` gives Ruined Base four continuous damaged walls, a south doorway, shattered windows, exposed brick/rebar, vines and a completely collapsed roof. Inside are two roof piles, fallen trusses, rubble, equipment racks, console, radio, mast, generator and abandoned stores. Container Yard gains **another 50% floor area over its previous footprint**, continuous chain-link fencing on four sides and a wide open south gate; it contains three long container placements (including a stack), one enterable end-on container, forklift, crane, cargo pallets, six drums and checkpoint equipment. `Main.CompoundBoundaries.cs` draws the depth-sorted native walls and cached diamond mesh; collision follows the same perimeter and the central passages stay clear of titanium. Expanded footprints avoid water and share their centres with map markers. `tools/TerrainPreview.tscn -- --compound-review` captures both sites and the map; ground/resource checks cover all four sides, player/boss gate access, precise area growth and entry/exit with resources present.

The entire irregular region uses opaque rock ground, including the beach edge and hidden routes; grass and random forest resources are excluded. The pump, rain barrel, pots, watering can and aged fence remain scenery. Herb nodes use the existing harvest stages and regrow at dawn. `Main.HerbGarden.cs` draws the soil beds and depth-sorted wooden fencing; `TerrainPreview.tscn -- --garden-review` captures the entire garden, gate and updated map. Towers go anywhere outside the base on open land, but never on a helicopter landing pad or within 3 tiles of a door; up to 3 per team. One free tower (built from the build menu (B) or with T by an Engineer on day 1, or it appears beside night 1's landing pad at dusk); more cost 10 wood + 5 titanium after the first boss. At night enemies walking into a tower's light attack it first (Wreckers x2, Spitters never); the Engineer repairs it like a door, a destroyed one only to 30% and only with no enemy in its light.
- Inventory (MEC-09, BAL-18): 8 slots of up to 20 (weapons 1 per slot), the first 4 are the hotbar; 40 shared storage slots in the storage chest by the north wall (east of door B; stand at it and press Tab, its lid opens as anyone walks up; Tab elsewhere opens only your own bag, and the bag opened at the chest closes as you walk away from it). The crafted bow holds its own arrows (up to 30, shown on its slot): arrows you get go into it first, dragging arrows onto it loads them, shots use loose arrows first, and a dropped or given bow takes its arrows along. Kits (team change to BAL-42, no basic weapon item): Scout a starter bow (the crafted bow's 12 damage, 1 shot/s and 8-tile range, but no arrows needed), Engineer the hammer, Healer empty hands and 3 flasks. With no weapon in the selected slot a player fights bare-handed with the GDD basic weapon's numbers (15 damage, 1.5/s, reach 1.5 tiles). Armour takes no slot: it is worn as soon as it is crafted, taken from storage or picked up (the best piece is kept; a tier already worn cannot be crafted again) and shows by the HP hexagon. Player-dropped items stay until picked up with E; enemy drops need free space.
- Crafting (MEC-10, BAL-19): use C at the workbench by the north wall, west of door B. The opaque panel shows tier tabs, recipe cards and material costs; use the button or a number key. Walking away or taking damage cancels without spending materials. Armour is worn on completion; a bow is empty until separately crafted arrows are loaded. Engineer generator repair is daytime-only, 5 stone for 100 HP over 5 s. Carry a Revival kit to a dead teammate and hold E for 3 s to revive them at 50% HP. The field repair kit restores a nearby door, wall or tower through its existing stationary channel. Crafting kits passively shorten recipe channels by 20%; they do not shorten chest unlocking or radio assembly.
- Walls (ITM-07, ITM-11, MEC-11, BAL-27): wood (5 wood, 200 HP) and stone (5 stone, 400 HP, after night 1), 3 tiles long, not within 3 tiles of a door; enemies walk around them and attack one that blocks them.
- Bosses (AGT-05..11, table 4.2): all seven archetypes; night 2 draws one at random and night 4 another (FML-05), announced at dawn. Each has the shared slam plus its move: Juggernaut charge, Broodmother summons, Bio-Cannon projectile ring, Burrower burrow, Gatebreaker 120-point door blow, Phantom cloak and ambush, Ironhide front armour. Every damaging move has a 1.0 s ground telegraph.
- HUD: phase and timer (top right; at night tonight's three supplies under it), generator and doors in red (top), the night bar (enemies down, no count), team list (left), HP, the armour worn (icon and name), bandages and healing flasks carried (bottom left), hotbar (bottom), minimap (top left: the island around you with the roads, base, doors A B C by state, a dot at each landmark's structure, towers, teammates, you and the camera view; no enemies, GDD 6.1). M opens the island map, large in the middle of the screen: a dot where each landmark's structure stands with its name in black beside it (labels placed so they do not overlap), the roads, landing pads, teammates with their names and the bays. Outside the base a gold arrow round your character points home. Teammates get a marker over the head; off screen they (and tonight's supplies) are pinned to the screen edge, pointing their way. Hints and messages are kept to a few words. Walking into a landmark's area shows its name for a few seconds. Damage per player is on the result screen.
- Result screen (section 2.5): win or loss with its cause (e.g. "Generator destroyed at door B"), night reached and per-player kills, revives, damage dealt and taken; Back to lobby. Esc opens a pause overlay (a solo match pauses).

## 2.5D look (branch `proto-2.5d`)
- The rules are still flat 2D (`GameSim` unchanged); only `Main` draws differently: everything with height (trees, rocks, walls, enemies, players) is sorted by the y of its foot, walls have a top and a front face, and bodies stand above their shadows. Scenery and resource nodes stay opaque even when a character stands behind them; a gathered node shows what is left of it (stump, rubble, cut stems, broken crystals) until dawn.
- Pixel-art world (GDD style guide): everything is drawn without smoothing, and the camera zoom keeps one art pixel on a whole number of screen pixels.
- Fonts in `fonts/` (GDD table 6.1; SIL OFL 1.1, licence files next to them, from the Google Fonts repository): **Noto Sans** (Google, weight 600) for all text, **Oswald** (Vernon Adams and contributors, weight 600) for titles, the timer, big numbers and banners. The UI is drawn at the window resolution, so the letters stay sharp.
- Base props in `art/props/` (lighthouse = beacon, workbench (2 tiles wide), storage chest (4 frames, shut to open), tower, wrecked tower, landing pad) are pixel art drawn by `tools/PixelProps.cs`; doors have lamp pillars that light up at dusk. The base itself is drawn in code (`src/world/view/Main.BaseLook.cs`): weathered cream concrete walls with pilasters, rust runs and moss at the foot, a stone-paved floor, and warm lamps (door pillars, two sconces on the north wall) that light it at night. The world light is a warm afternoon sun by day and a deep teal night where only the lamps, the beacon and tower lights glow orange; the base stands on the grass; no letters are drawn at the doors (the HUD door bars name them).
- Nature sprites in `art/nature/` (pines, dead trees, rock outcrops, shrubs, grass tufts, pebbles, the four resource nodes and their gathered remains, the ground texture) are pixel art at 1 px = 1 game px drawn by `tools/PixelNature.cs`; titanium nodes are dark slate rocks grown with blue and violet crystals that pulse and twinkle in game (`node_titanium_glow_*` is the crystal layer), so they never pass for the pale grey stone (GDD 4.3). See `art/nature/CREDITS.txt`.
- The island follows the level-design map "Hold 'til Dawn - Island Map", drawn 1.5 times its size (`IslandMap.SCALE`: about 230 x 210 tiles; 18 landmarks, 3 main gathering routes). Only the island grows: the base, its landing pads, the 20-tile safe zone, the night spawn bands and the boss distance keep their sizes, and the wood, stone and herb clusters by the outpost move in to stay inside the safe zone. `tools/island_from_pdf.py <pdf>` reads the PDF (its map picture pixel by pixel, its routes, trails and landmark numbers by their coordinates) and writes `maps/island_map.json`: the coast, the inner edge of the 4-6 tile beaches, the shallows, the hills, the woods, one point per tree, the routes, trails, landmarks and bays, in tiles from the outpost. `src/world/IslandMap.cs` loads it for every peer: the sea is impassable (players, enemies, bosses and bots slide along the coast; the bots' A* grid marks the sea solid), spawns are pulled inland, and scenery grows from the map's trees and woods. Terrain (`src/world/WorldTerrain.cs`, drawn by `src/world/view/Main.TerrainView.cs`): the sea stepping up through the shallows, the beach with a wet edge and rolling surf, grass lighter in the safe zone, darker woodland floor, walkable hills drawn with contour steps, the main routes, exploration trails and dirt roads out along the three door axes to the boss spawns, the Rainwater Pond (15) and the Mangrove Swamp (08: mud, wet patches and pools with reeds), the walkable limestone chamber of Southwest Cave (16). Ponds and pools block movement but not arrows or spit; cave walls block both. Resource nodes sit at the landmarks: wood at 02 Coconut Grove, stone at 03 Limestone Flats (and 16), herbs at 04 Herb Meadow (and 15, 18), three in four of each in the safe zone; titanium spread over the five salvage sites 05, 06, 07, 13 and 14, with additional veins inside Southwest Cave (16). Night enemies spawn in a 10 x 10 tile band 25-35 tiles out on each active door's axis; bosses 60 tiles out. The base and its landing pads are unchanged.
- Landmarks are built after the concept art of the "Hold 'til Dawn - Island Landmark Atlas" (one picture per landmark in `art/landmarks/ref/`, kept out of the Godot import by `.gdignore`). `tools/PixelLandmarks.cs` (part of the PixelNature tool) draws their pixel art into `art/landmarks/` + `index.json`, and `src/world/WorldLandmarks.cs` places it from the island's shape, the same on every peer: coconut palms, a fallen trunk and dry branches in the Coconut Grove (02); low limestone shelves (03); broad-leaf herbs with purple spikes along the meadow trail (04); the military utility vehicle slid off the road (05); the Ruined Base's concrete floor, broken walls with rebar and vines, shelves, crates and radio mast (06); three convoy trucks beside their track, one with its canvas torn open on crates (07); mangroves on stilt roots round the swamp pools (08); the weather station with its wind vane and aerial (09); the Old Fishing Pier out over the sea with fish traps on the beach (10, walkable: `IslandMap.Docks`); stone steps up the Northwind Slope between rocky shoulders (11); the tin-roofed lookout on stilts over a coral reef (12); the Container Yard's concrete, containers (stacked, end-on with its doors open) drums and pallets (13); the cargo ship aground on the south-east beach, its hull split open, machinery washed up round it (14); red ginger and lily pads at the Rainwater Pond (15); the limestone bluff over the cave mouth (16); the concrete lookout platform at the tip of the south cape (17); six harvestable herb beds, a solid perimeter fence, a south gate and water equipment in the Abandoned Herb Garden (18). Every prop a landmark places (palms, shelves, herbs, mangroves, beds, the Northwind and South Cape rocks...) is scenery that cannot be gathered, so each place keeps its look when everything round it is cut down; the natural resource scenery, cave ore/scree and 36 plants inside the herb garden are harvestable. Standing structures are depth-sorted scenery with solid circles; floors, the pier, the platform, steps, coral and lilies lie on the ground layer (`src/world/view/Main.LandmarkView.cs`). The minimap shows them.
- Characters, enemies and bosses have 8 facing directions (sheet rows: right, down, left, up, down-right, down-left, up-left, up-right); the diagonals are 3/4 views (players and enemies: the front / back pixel map with the face redrawn turned, in `tools/PixelChars.cs`; bosses: built by `tools/PixelTurn.cs`, which never cuts through an eye). Both eyes keep the front view's size in the diagonals. The facing changes only once the angle is clearly past the edge between two directions, so diagonal walking does not flicker.
- Players and enemies in `art/chars/` are 32x32 pixel art (Wrecker 40x40) of the GDD characters (CHR-01..03 Scout, Healer, Engineer; CHR-05..07 Grunt, Spitter, Wrecker), drawn by `tools/PixelChars.cs` (pixel maps, GDD palette, outline, 8 directions, idle + walk); see `art/chars/CREDITS.txt`. Each sheet cell has 8 px of room around the body (48x48, Wrecker 56x56; `chars.json` gives the cell `size` and the character's own `body` size). After idle and walk, the sheets have fight and knock-down frames from `tools/PixelPoses.cs` (listed under `anims` in `chars.json` / `bosses.json`, 4 frames each): players one attack per weapon (bare-hands jab, stone-spear thrust, titanium-blade slash with a smear, overhead hammer smash with dust and cracks, bow draw and release), the Grunt a claw rake, the Spitter a spit, the Wrecker a two-fist ground smash, each boss a wind-up / slam / impact / recover; then everyone a fall (hit, knees give, falling, lying with the eyes shut). The arm, weapon and effect are posed in 3D around the body and projected to each of the 8 views; seen from the back the body hides them. The PNGs can be repainted by hand. A coloured ring at a player's feet shows the role.

## Dev
- No build step. Run all regression checks with `powershell -File tools/Test.ps1 -Godot <path-to-Godot-console.exe>` (geometry and rules; the network suite is in git commit `cf44b5f` ("Port to C#")). The full simulation suite advances many minutes of game time and can take several minutes.
- Settings (one file per owner, edit in Godot's Inspector, restart the game after a change): `config/gameplay/gameplay.tres` (vote delay, dusk), `config/ai/ai.tres` (enemy speed, wave timing, spawn/roamer/drop multipliers), `config/world/world.tres` (resource nodes), `config/display/display.tres` (camera follow). Defaults follow the GDD (180 s minimum before the skip vote, 15 s dusk, waves at 30 s then every 90 s / 45 s, speed and spawn/roamer/drop/node multipliers at 1); raise the multipliers or lower `DayMin` only for local playtests.
- Editable landmarks: open `maps/island.tscn` in Godot's 2D editor. Duplicate `ExampleRock`, move it, choose a nature PNG in Texture (keep Scale at 1 so the pixels stay square), and adjust `Solid Radius` / `Blocks Attacks` in the Inspector. Position is the ground anchor; the script aligns nature textures automatically. Keep these Sprite2D objects as direct children with zero rotation. The procedural forest remains, and every peer reads the same landmark scene. Restart after map edits.
- Combat: solid scenery and intact base walls block melee, enemy sight, tower fire and Spitter projectiles. Projectiles test their complete movement segment and stop at the nearest obstacle/player. Destroyed towers remain physical wrecks. Harvested resource colliders disappear until dawn.
- Presentation: activity states are sent in snapshots; gathering plays each character's own 6-frame, 8-direction harvesting sprites (axe for wood, pickaxe for stone/titanium, crouch and hand-pick for herbs; `tools/PixelGatherPoses.cs`); repair shows a swinging tool, healing/reviving show a pulsing cross, and an attack plays the sprite frames of the weapon in hand once (`src/gameplay/view/Main.Anim.cs`); the long spear thrusts out and back and the stun maul comes down overhead with a shock ring, drawn over the spear / hammer frames; flasks fly in an arc and splash, vine traps sprout, explosive arrows burst with sparks, a hasted player leaves streaks, and throwing or drinking plays a short throw (`src/gameplay/view/Main.TacticalItems.cs`); a knocked-down player falls over and lies still until revived; enemies show their attack frames on each hit or spit (snapshot field 9), a boss holds its wind-up frame until the move lands, and a dead enemy falls where it died, lies there and fades (`src/ai/view/Main.EnemyView.cs`). Bosses are drawn at 3x their 48 px sheets (1.5 times the previous 2x presentation) with a 1.1-tile body radius, so they still fit through a door gap. From outside the base you cannot see in: a flat roof of riveted slabs in the walls' cream concrete, rusting at the seams, with vent grates covers it between the wall tops, nobody and nothing inside is drawn, and only the part of the lighthouse above the roof shows, rising out of a steel collar; the roof fades away when you step inside (`src/world/view/Main.BaseFog.cs`). The lighthouse fades while you stand behind it (`src/world/view/Main.BaseProps.cs`). Animation timing restarts when the state changes. Existing character PNGs are preserved. Camera follow uses a dead zone and exponential smoothing, snapped to whole screen pixels; your own character moves every rendered frame. The walk cycle bounces the body a pixel per stride (10 fps). A resource node breaks bit by bit as it is gathered instead of shrinking (5 units, each unit taken while someone holds E): every unit taken swaps in the next of four broken stages (`art/nature/<node>_dmg<k>_<variant>.png`, drawn by `tools/PixelNature.cs`: pieces knocked out, cracks, chips on the ground), the node jolts and a burst of chips in its colours flies off; while it is being worked it shakes and throws small chips (`src/world/view/Main.NodeBreak.cs`).
- F3 toggles collision outlines for playtesting. Enemy separation and scenery queries use spatial buckets; the renderer culls against the actual camera view at every zoom level.

### Night CPU checks

`godot --headless --path . tests/NightSpawnCheck.tscn` validates paced arrivals, first-night rest periods, per-night caps, large clock jumps, phase cleanup and fair navigation scheduling.
`godot --headless --path . tools/NightSpawnProfile.tscn -- --night=1` (or `--night=5`) samples 1800 director ticks at 60Hz, with enemy AI/body updates at 20Hz on a seeded three-player island, excluding rendering; timings depend on the machine.

Enemy creation uses typed stats, RNG and collision resolution. Navigation uses typed collider/segment tests and native AStarGrid2D calls (`src/world/WorldGeometry.FastNavigation.cs`), caches coastline spans across collider revisions and caches routes for unchanged start/end cells. Collider changes invalidate the route grids. Enemy route recalculations are limited to two per tick with rotating priority and staggered refresh times; enemy body/collision/target decisions run at 20Hz, and snapshots interpolate their motion. Bot brains also run at 20Hz; player input/movement stays at 60Hz. Static resource collision checks run at 10Hz and newly placed structures rebuild immediately. A spatial index restricts scenery/resource rendering to the camera region, avoiding a full forest scan each frame. The reported maximum timings include first-use navigation costs; `--every-frame` compares the same scenario with enemy body work at 60Hz. These are CPU measurements, not a guarantee of fan noise on a particular laptop.

`godot --headless --path . tests/SurvivalWorldCheck.tscn` checks the expanded terrain, the two rivers (coast to coast, three west / two east bridges, both western expedition sites requiring a crossing, walkable decks for a boss, blocked water, enemy routes over the bridges, no path, prop or landmark in the water), non-harvestable props, 20 exploration chests outside the home farms, persistent team radio progression, the pre-night-5 assembly deadline and extraction gating, construction interruption/payment and the 20Hz AI budget. `godot --path . tools/SurvivalPreview.tscn` saves six actual-renderer review images under `.tmp/survival-preview/`.
